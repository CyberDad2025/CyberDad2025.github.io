The twelve games

Thanksgiving

  1. Table Talk Trails: conversation paths
  2. Harvest Category Sprint: category lists with letter rules
  3. Thanksgiving Mix-Up: ten letter scrambles
  4. Pass-the-Plate Sketch: drawing telephone
  5. Gathering Forecast: predict other players’ choices
  6. Thankful Alphabet Relay: a cooperative memory chain

Christmas + winter

  1. Winter Word Hunt: ten hidden words
  2. Parcel Clues: describe a target without its blocked words
  3. Snowfall Story Switch: fold-and-pass writing
  4. Ribbon Route: a single-path maze
  5. Seasonal Priority Shuffle: rank an imaginary gathering
  6. Holiday Table Logic: deduce seats and paper decorations

Player counts and times on each game are approximate. Each page lists its own players, time, materials, and copies. A timer is not required. A group playtest of these games has not been performed.

Before you print

The host guide says to choose US Letter or A4 to match your paper, then print portrait, single-sided, at 100% / Actual size. Do not use borderless printing. Test page 3 first. If the printer clips it, use Fit to printable area. Use plain paper and pens or pencils. No cutting is needed. Dashed lines are fold guides. A physical print test has not been performed.
