Kids' Table activities for Thanksgiving

A kids' table stays happier with a pencil, a placemat and a few quiet puzzles while the meal finishes. CyberDadKit's Kids' Table Activity Pack marks every page Simple or Trickier so guests can pick a starting point. Below is how to use the free Harvest Placemat sample and what else is in the full pack.

Set the table in three steps

  1. Print the free sample (cover, host note and Harvest Placemat) at 100% / Actual size on plain paper.
  2. Put crayons or pencils in a cup. Keep any answer-key pages with the grown-up host.
  3. Invite each guest to draw a favorite dish on the plate, count the leaves, finish the pattern and play the small tic-tac-toe grid.

What is on Harvest Placemat

Harvest Placemat is activity 1 in the pack (page 3), marked Simple. On one page you:

  • Draw

    A “My plate” box for a favorite dish.

  • Count

    Count the leaves (not the acorns) and write the number.

  • Pattern

    Draw what comes next in a short pattern row.

  • List and play

    Name three orange foods, then play a quick tic-tac-toe.

Common questions

Do I need scissors?

No cutting is required for most pages. The Thankful Place Card in the full pack uses one fold line.

Are answer keys included?

Yes, in the full pack (pages 17–18). Keep them with the host. The free Harvest Placemat sample does not need an answer key for the drawing and tic-tac-toe parts.
