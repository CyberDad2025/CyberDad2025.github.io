Thanksgiving games you can print tonight

The best printable Thanksgiving games fit between courses: conversation paths, short word games and drawing games that do not need a timer or a screen. Here is a simple way to pick one, print a free sample and run it at the table.

Pick the right kind of game

  • Conversation

    Table Talk Trails uses starting prompts and follow-up questions. No pens required. Good while plates are still out.

  • Wordplay

    Category lists and letter scrambles work with a pencil. Keep answer keys with the host.

  • Drawing

    Pass-the-plate sketch needs scrap paper and a pen. Plan a few minutes between bites.

How to run Table Talk Trails

Table Talk Trails is one unchanged Thanksgiving game from Gather & Play (page 3 of the paid PDFs). It is free to print in US Letter and A4.

  1. Download the free sample and print one page, portrait, at actual size.
  2. Read a starting prompt aloud. Let the person on your left answer, then follow the next question on the path.
  3. Skip any prompt that does not fit your table. There are six starting paths on the page.
  4. When you want more, Gather & Play has five more Thanksgiving games and six Christmas or winter games in the same download.
